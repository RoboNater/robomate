# Historical documents

Frozen records from earlier phases of the project. They are kept for history and
are **not maintained**: do not edit them, except to repair a link or path that a
later move broke. Their bare issue numbers refer to `RoboNater/robo-agents`, where
the proof of concept was built.

- [`poc/`](poc/): PoC planning documents and runbooks (Step 5–7 acceptance, the
  sandbox repository plan), the PoC worklog, and PoC-era notes.

PoC material that is still read as live reference stays outside this folder:
[`docs/poc-spec.md`](../poc-spec.md), [`docs/poc-readme.md`](../poc-readme.md) and
[`docs/poc-lessons.md`](../poc-lessons.md), which the MVP spec and the tests cite,
and the run evidence in [`docs/evidence/`](../evidence/), which scripts read by
default.
