## The 172.26.x addresses

`172.26.115.68` (WSL `eth0`) and `172.26.112.1` (the Windows vEthernet adapter)
are private `172.16.0.0/12` addresses on the Hyper-V NAT switch inside this one

on restart. `export` keeps them on purpose: they are check 1's boundary
evidence. It masks the WSL and Windows run roots (`wsl:/RUN`, `windows:/RUN`)

## Disclosed limits

- **One physical machine.** WSL2 and the Windows host are separate network
  stacks, operating systems and filesystems, and Bob's every call crossed the
  Hyper-V vSwitch, but no packet crossed a physical link.
- **NAT mode.** The hub's address is WSL's NAT `eth0`, which changes on WSL
  restart; the LAN cannot reach it. Plain HTTP relies on the §1 trust
  assumption, which holds only because the address is confined to this PC.
- **Control plane through interop.** The control session launched Bob through
  WSL interop and read his transcript and telemetry through `/mnt/c`, not over a
  remote transport.
- **Only Bob was remote.** Charlie stayed in WSL on loopback, partly because
  Codex on Windows is affected by #84.
- **No link disruption.** The run had no network interruption, so it does not
  exercise recovery shorter or longer than `HUB_LOST_AFTER_S`.
- **Stability over one check-in.** Each worker checked in once, so
  `step7_stable_workspace_ids` covers a single check-in plus the heartbeat
  samples, not a reconnect.
- **Re-verification, not a fresh run.** The passing result comes from
  re-verifying the recorded run with a loosened verifier string comparison
  (#145), as the verification note discloses.
- **Carried over from Step 6.** Private branch protection is unavailable
  (HTTP 403, GitHub Pro or public visibility required), so the residual race if
  `main` moves between the final gate and merge remains. Shared GitHub
  credentials and clone access remain guide boundaries, and the recorded-call
  audit is not OS-level isolation.

[#127](https://github.com/RoboNater/robo-agents/issues/127) defers the
multi-machine hardening: both workers on other physical LAN machines, SSH
launch and collect, link disruption below and above `HUB_LOST_AFTER_S`, Codex
Charlie on Windows once #84 allows it, and clock skew.
